# Ventas · Tarjetas de objeciones (chuleta para las llamadas)

> Tenelo abierto al lado (o imprimí) durante las llamadas. Cada tarjeta: la objeción, la técnica, y la
> respuesta lista. **Técnica base: Validá → Reencuadrá → Probá (TBM) → Devolvé la pregunta.**
> Regla mental: una objeción no es un "no". Es un "todavía no me convenciste de esto puntual".

## Las 3 reglas de oro (grabátelas)
1. **Nunca discutas.** Validá primero, siempre. "Te entiendo" antes de responder.
2. **Después del precio, callate.** El que habla primero, pierde. Bancá el silencio.
3. **Pedí el siguiente paso.** Toda llamada termina con una acción concreta (agenda + anticipo).
